# Turvleto Content Engine

Система подготовки ежедневных тем и черновиков публикаций для бренда «Тур в лето с Навигатор».

## Что делает

- Предлагает ровно 3 новые темы для русскоязычных туристов во Вьетнаме.
- Проверяет точные и близкие повторы по истории.
- Сохраняет историю предложенных тем.
- Хранит проверяемые утверждения и ссылки на источники.
- Проверяет техническую доступность ссылок и сохраняет отдельный JSON-отчёт. Это не заменяет проверку фактов редактором.
- По выбранной теме создаёт отдельные черновики Telegram и MAX и идею обложки.
- Не публикует материалы автоматически.

## География и тематики

Нячанг/Кханьхоа, Дананг, Фукуок, Муйне. Экскурсии, транспорт, въезд и пребывание, безопасность, сезонность, туристические новости, советы, цены и сервисы.

## Настройка

1. Добавьте GitHub Actions Secret с именем `OPENAI_API_KEY`.
2. При необходимости задайте модель через переменную `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`).
3. Откройте Actions → Turvleto Content Engine → Run workflow.
4. Проверьте созданный файл в `content/selected/` и отчёт в `content/source-checks/`.

## Локальный запуск

Требуется Python 3.11+.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python src/content_engine.py generate
python src/content_engine.py draft --file content/selected/topics-YYYY-MM-DD.json --topic 1
python src/check_sources.py content/selected/topics-YYYY-MM-DD.json --report content/source-checks/source-check-report.json
```

## Рабочий процесс

1. Генератор создаёт три темы и проверяет их на дубли.
2. Workflow проверяет техническую доступность URL и сохраняет отчёт в `content/source-checks/source-check-report.json`.
3. Темы и дата сохраняются в истории и отдельном JSON-файле.
4. Пользователь выбирает тему.
5. Команда `draft` создаёт тексты Telegram/MAX и идею обложки.
6. Пользователь проверяет факты, редактирует и самостоятельно публикует материал.

## Источники и достоверность

Проверка доступности URL не подтверждает достоверность сведений на странице и не доказывает, что источник поддерживает конкретное утверждение. Даже доступные ссылки остаются на ручной редакционной проверке; недоступность URL также может быть вызвана блокировкой автоматических запросов. Изменяемые факты (цены, расписания, правила въезда, ограничения, события) требуют проверки первоисточника и редакторского подтверждения. Неподтверждённые сведения нельзя публиковать как факт.

## Автоматизация

Workflow пока запускается вручную. Ежедневное расписание 08:00 по Вьетнаму (01:00 UTC) оставлено закомментированным до завершения редакционного контроля.

## Безопасность

Не храните API-ключи в исходном коде или JSON-файлах. Используйте GitHub Actions Secrets. Публикация в Telegram/MAX не подключена и не выполняется.
