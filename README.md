# Turvleto Content Engine

Система подготовки ежедневных тем и черновиков публикаций для бренда «Тур в лето с Навигатор».

## Назначение

- Предлагать ровно 3 новые темы ежедневно для русскоязычных туристов во Вьетнаме.
- Исключать повторы по истории и смысловому сходству.
- Проверять факты и сохранять источники, даты проверки и статусы.
- По выбранной теме готовить отдельные черновики для Telegram и MAX.
- Предлагать идею обложки в фирменном стиле.
- Оставлять окончательное решение и публикацию пользователю.

## География

Нячанг и провинция Кханьхоа, Дананг, Фукуок, Муйне.

## Тематики

Экскурсии и маршруты, транспорт, въезд и пребывание, безопасность, сезонность и погода, туристические новости, практические советы, цены и туристические сервисы.

## Принципы

- Не выдумывать цены, адреса, расписания и другие факты.
- Указывать источники и дату проверки для проверяемых утверждений.
- Не повторять ранее предложенные темы.
- Писать кратко, содержательно и по-русски.
- Использовать бренд «Тур в лето с Навигатор» и палитру бирюзовый/золотой.
- Не публиковать автоматически: только подготовка материалов и подтверждение пользователем.

## Планируемая структура

```text
.github/workflows/  # расписание и CI
config/             # тематики и бренд
content/history.json
content/selected/   # выбранные темы
content/drafts/     # черновики
prompts/            # инструкции генерации
src/                # генерация, проверка источников и дублей
tests/              # тесты
```

## Расписание

Целевое время ежедневной подготовки — 08:00 по Вьетнаму (UTC+7). Включать расписание только после отдельного подтверждения.

## Безопасность

Секреты и токены хранить только в GitHub Actions Secrets или другом защищённом хранилище. Не добавлять их в исходный код.
